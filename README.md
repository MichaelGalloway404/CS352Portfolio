# Generative Art Portfolio using (p5.js)

A collection of **generative digital art projects** created using **p5.js**(not AI but art made through coding). This portfolio explores algorithmic drawing, animation, and interactive visual design using JavaScript.

## Overview

This project showcases a series of creative coding exercises developed while learning **p5.js**, a JavaScript library for visual and generative art. Each piece demonstrates different techniques such as procedural drawing, animation loops, and interactive visual effects.

## Key Features

- **Algorithmic art generation** using p5.js
- **Canvas-based rendering** with JavaScript
- **Animated visual patterns and shapes**
- **Interactive visual experiments**
- Multiple sketches exploring different creative coding concepts

## Technical Highlights

- Use of the **p5.js drawing lifecycle** (`setup()` and `draw()`)
- Procedural generation using **math functions and randomness**
- Real-time rendering using **HTML5 canvas**
- Modular sketches demonstrating different visual algorithms

## Technologies Used

- JavaScript
- p5.js
- HTML
- CSS
